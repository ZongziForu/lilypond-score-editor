# 乐器音域与记谱陷阱

在写音乐之前了解乐器的可演奏音域。LilyPond 会愉快地排版超出乐器实际音域的音符——输出看起来正确但实际无法演奏。

## 常见乐器音域

| 乐器 | 记谱音域 | 说明 |
|------|----------|------|
| 小提琴 | G3 – E7（实用：G3 – D7） | 避免在 G3 以下持续演奏（空弦 G）；高把位可行但避免长时间 C7+ |
| 中提琴 | C3 – E6 | 中音谱号；空弦 C 为最低音 |
| 大提琴 | C2 – C6 | 低音谱号（高把位使用次中音/高音谱号） |
| 低音提琴 | E1 – G4 | 实际发音比记谱低一个八度 |
| 长笛 | C4 – C7 | 低音区（C4–C5）轻柔；中音区（C5–C6）明亮；高音区（C6+）可能尖锐 |
| 单簧管 | E3 – C7 | 记谱音高（实际发音取决于移调） |
| 小号 | F#3 – C6 | 记谱音高（Bb 小号实际发音低大二度） |
| 法国圆号 | F2 – C6 | 记谱音高（F 圆号实际发音低纯五度） |
| 长号 | E2 – F5 | 低音谱号 |
| 钢琴 | A0 – C8 | 全 88 键范围；中间两个八度（C3–C5）的柱式和弦最温暖 |

## 钢琴写作陷阱

### 1. 右手音区（最常见的错误）

不要在小提琴独奏旋律的同一八度内写钢琴右手的柱式和弦。和弦音会掩盖旋律。钢琴和弦应放在独奏声部 **下方 1–2 个八度**。

```
小提琴： g''4 b'' d'''   (G4–D5)
钢琴：   <g b d'>        (G3–D4) ← 低一个八度，温暖且衬托型
         不要 <g' b' d''> (G4–D5) ← 与旋律冲突
```

### 2. `\relative` 模式与和弦

`\relative` 模式以前一个和弦的**最后一个音**作为参考。这会导致连续和弦在未标明八度标记时逐渐向上或向下漂移。

```lilypond
% 错误——音区漂移：
\relative c' {
  <g b d>2. |  % G3 B3 D4  (正常)
  <g b d>2. |  % G4 B4 D5  (向上漂移！)
}
```

**修复 1——绝对音高**（推荐用于所有和弦声部）：
```lilypond
{
  <g b d'>2. |  % G3 B3 D4 — 始终准确
  <g b d'>2. |  % G3 B3 D4 — 相同
}
```

**修复 2——八度标记**（如果必须使用 `\relative`）：
```lilypond
\relative c' {
  <g b d>2. |   % G3 B3 D4
  <g, b d>2. |  % G3 B3 D4 — 使用 `,` 强制降低
}
```

### 3. 和弦排列

钢琴中音区（C3–C5）的柱式和弦（`<c e g>`）听起来最温暖。
- C3 以下：柱式和弦会变得浑浊（低音区的密集排列）
- C5 以上：柱式和弦对持续伴奏来说变得单薄

在中音区的柱式和弦建议使用**密集排列**（音符集中在一个八度内），低音区和弦建议使用**开放排列**（跨越一个以上八度）。

## 力度标记位置

力度标记（`\p`、`\mf`、`\dim` 等）必须直接附着在音符上或之前使用不可见音符。将它们放在音符之间的独立位置会导致"缺少附着对象"警告。

```lilypond
c4\p d e f |            % 正确——附着在 c4 上
\p c4 d e f |            % 错误——警告
c4 d e f |
\dim c4 d e f |          % 错误——警告
```

## 最后一小节的拍号

最后一个小节必须遵守拍号。在 `3/4` 拍的小节中使用 `1`（全音符，4 拍）会触发小节检查警告，即使后面跟着 `\fermata`。

```lilypond
% 3/4 拍中错误：
g2. | b1\fermata \bar "|."  % b1 = 4 拍，在 3/4 拍小节中——警告

% 3/4 拍中正确：
g2. | b2.\fermata \bar "|."  % b2. = 3 拍——正确
```

如果希望最后的音符保持延长，可以：
- 使用符合拍号的正确时值（3/4 拍用 `2.`，4/4 拍用 `1`）
- 在最后一个小节前更改拍号：`\time 4/4 b1\fermata`

## 圆滑线用法

LilyPond 中有两种类型。不要在同一个声部中混用：

| 圆滑线类型 | 语法 | 用途 |
|-----------|------|------|
| 普通圆滑线 | `c( d e)` | 声部内的分句，每个声部 ≤1 条活跃 |
| 分句线 | `c\( d e\)` | 长距离分句，可跨越 `\bar`，但嵌套能力有限 |

在分句线内嵌套普通圆滑线（或反之）是可行的，但在同一个声部中**同时激活两条分句线**（`\(` 嵌套 `\(`）会导致警告和错误输出。每行音乐只使用一种类型。
