# 错误修复指南

## 通用原则

不要因为一个错误就重写整个文件。查看错误行及其前后约 20 行。许多错误是由文件中前面部分的不匹配花括号、遗漏时值或拼写错误引起的。

## 语法错误 / 意外的标记

- **原因**：缺少花括号、意外的符号、关键字位置错误。
- **检查**：查看行号及其前一行，检查是否有未闭合的 `{`、`<<`、`(` 或 `[`。
- **修复**：添加缺少的分隔符或删除多余的标记。

## 未知转义字符串 / 不是音名

- **原因**：拼写错误，如 `\abc` 或在英语命名中使用了 `h` 而不是 `b`。
- **检查**：验证音名和命令拼写。
- **修复**：修正拼写错误。

## 小节检查失败

- **原因**：小节内的音符时值加起来不等于拍号规定的时值。
- **检查**：计算被标记小节中的时值。
- **修复**：添加缺失的休止符、修正时值，或纠正拍号。

## 找不到文件

- **原因**：`\include` 路径错误或文件缺失。
- **检查**：检查相对于被编译文件的路径。
- **修复**：修正路径或创建缺失的文件。

## 参数类型错误

- **原因**：将音乐传递给需要字符串的函数，或反之。
- **检查**：检查函数签名。
- **修复**：正确包裹或解包参数。

## Guile/Scheme 错误

- **原因**：`#(...)` 内的 Scheme 表达式无效。
- **检查**：查看错误行附近的 Scheme 表达式。
- **修复**：修复引号、括号或函数名。

## 不匹配的花括号 / `<< >>`

- **原因**：缺少闭合的 `}`、`>>`、`)` 或 `]`。
- **检查**：使用编译器的提示；如果没有，对文件进行二分定位或使用括号匹配编辑器。
- **修复**：添加缺失的闭合符号。

## 歌词不对齐

- **原因**：音节数与可用音符数不匹配（通常由连音线或圆滑线引起）。
- **检查**：将歌词音节与音符事件进行对比。
- **修复**：为同音延音添加 `__` 或调整歌词。

## 警告 vs 致命错误

- 警告通常仍能生成输出，但表明排版存在问题。
- 致命错误会停止编译。先修复致命错误，再审查警告。

## 修复示例

已知：
```lilypond
\relative c' { c4 d e f | g2 g }
```

错误：`syntax error, unexpected '}'`
原因：缺少小节检查或 `|`。在这个极简示例中可以编译，但在更复杂的文件中请仔细检查嵌套。
